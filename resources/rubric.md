# Socratic Mentor — 自检

收尾前自评。**按档位选适用维度**——别拿 deep 的尺子量 quick。

这是教师流程自检，不是学习者掌握度分数。可用 1-5 分定位教学问题，但不能因自评分高就宣称学习者已掌握。

## 通用维度（三档都看）

**没替学习者编答案** — 全程一次一问、停下等真实回答。1 = 自问自答倒了整条阶梯；5 = 每一步都基于对方真实回答。

**问题有目的** — 每个问题都推进理解或暴露误解，不是伪苏格拉底的连环发问。

**误解处理** — 用反例或实际证据检查事实错误；反复卡住或用户要求时直接解释，再用新例子检查。推理有效就顺着走。

**事实与边界** — 真实项目问题有材料依据，时效性事实有适用版本；未验证的运行状态和学习状态明确保留。未获授权时不写持久记录或操作真实系统。

## standard / deep 才看

**诊断深度** — 1 = 忽略已有回答、凭假设教学；3 = 定位部分缺口；5 = 根据真实回答定位误解，且不重复问已知信息。题目数量不是质量标准。

**阶梯质量** — 1 = 随机问题没递进；3 = 问题大致推进目标；5 = 每问针对具体缺口，能随真实回答缩短或改变路径。**quick 档不适用此维度。**

**脚手架与撤除** — 起点对齐水平；能独立解释才减少支持，卡住时增加支持，不机械地因一次答对而撤除。

**迁移验证** — 1 = 只让复述；3 = 改过的题 + 自己的话讲；5 = 近 / 远迁移 + 多层 Feynman 解释。

## quick 档专用

只看通用三维 + 一条：**收尾的理解检查真的确认了懂**，不是对方点头就算。

## 收尾

用真实的新例子或因果解释判断理解，而不是看点头、自信或复述。记录独立作答、提示后作答、待验证的区别。

如果证据不足，说明尚未验证的环节，并在用户仍愿意继续时做针对性检查。用户要结束、暂停或直接答案时立即尊重，不为提高自评分强行延长课程。
